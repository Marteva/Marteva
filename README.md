# Hi, I'm Marteva 👋

I work with **network inventory systems** – the software that keeps track of what a
network really consists of: devices, interfaces, links, services and how they all fit
together. At home I apply the same mindset to my own network: if something is
connected, I want to know what it is and what it talks to.

### What I'm into

- 🗂️ **Network inventory & OSS** – modelling networks and keeping the data in sync with reality
- 🔐 **Network security** – visibility first: know what is on the network and where it connects
- 📡 **MikroTik / RouterOS** – firewalling, VPNs, VLANs, containers running right on the router
- 🏠 **Home automation & self-hosting** – smart home, DNS filtering, NAS, homelab
- 🛠️ **Go & automation** – small, reliable tools with tests and CI

### Featured project

#### 🛡️ [Guardian for RouterOS](https://github.com/Marteva/routeros-guardian)

A home-network anomaly watchdog that runs as a container **directly on a MikroTik
router**. It learns what is normal for every device and alerts you via Telegram or ntfy
when a camera starts talking to a new country, a smart plug uploads gigabytes or an
unknown device joins the network. One-click quarantine, web UI in 7 languages, no cloud.
